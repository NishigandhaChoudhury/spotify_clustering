# 🎵 Spotify Music Clustering

A machine learning project that clusters Spotify songs based on audio features using KMeans clustering.

## Features Used
- Danceability
- Energy
- Tempo
- Loudness
- Valence

## Tech Stack
- Python, Scikit-learn, Pandas
- Streamlit (for deployment)
- KMeans Clustering, PCA, t-SNE

## How to Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
